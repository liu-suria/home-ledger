Family Hub API

Beta v2.9.0 RC · Data Version 8
返回事务中心

鉴权与通用约定

在 EdgeOne 环境变量中配置 API_KEY。外部请求任选一种方式携带：

X-API-Key: 你的 API_KEY

Authorization: Bearer 你的 API_KEY

网页已登录时也可通过 Session Cookie 调用。写接口统一使用 Content-Type: application/json。日期格式为 YYYY-MM-DD，币种使用大写代码。

GET/api/types

查询当前可用类型。

{ "types": [{ "id": "baby", "name": "👶 宝宝" }] }

GET/api/events

查询事项，可组合筛选。

参数说明
days从今天起查询未来 X 天，0–3650
type类型 ID
statuspending 或 done
keyword搜索标题、备注、支付方式和币种
start / end日期范围
calendarsolar 或 lunar
GET /api/events?days=30&type=baby&status=pending

POST/api/events

新增一条单次事项。

字段必填说明
title是标题，最多 100 字
type是类型 ID
date是日期
calendar否默认 solar
lunarMonth / lunarDay农历时农历月、日
amount否金额，最多两位小数
currency否默认 CNY
payment / note / icon否支付方式、备注与 Logo
{
  "title": "宝宝疫苗",
  "type": "baby",
  "date": "2026-08-15",
  "calendar": "solar",
  "currency": "CNY"
}

PATCH/api/events?id=事项ID

修改事项或切换完成状态。

{ "title": "修改后的标题", "date": "2026-08-20" }
{ "action": "done" }
{ "action": "restore" }

DELETE/api/events?id=事项ID

直接删除指定事项，不进入回收站。

GET/api/today

查询今天未归档事项。

GET/api/stats

返回今天、未来 7 天、未来 30 天、逾期、完成数、总数、订阅数与一年内人民币金额。

GET / POST / DELETE/api/templates

GET 查询模板；POST 保存或应用模板；DELETE 删除个人模板。

{ "action": "apply", "id": "baby-basic", "startDate": "2026-08-02" }

{ "action": "save", "name": "出行准备", "items": [] }

GET/api/calendar?days=365

导出指定天数范围内的 ICS 日历文件。

GET / PUT/api/ledger

读取或覆盖保存完整账本，主要用于备份和迁移。

{
  "version": 8,
  "settings": { "siteName": "Family Hub", "types": [], "typeOrder": [] },
  "series": [],
  "events": [],
  "templates": []
}

GET / POST/api/series

GET 查询循环规则；POST 更新、暂停、补齐或删除规则。

字段说明
id循环规则 ID
actiontopup、toggle、update、delete
patch更新规则时的新字段
rebuildAll更新后清理普通未来实例并按两条窗口重建
{
  "id": "series-xxx",
  "action": "update",
  "rebuildAll": true,
  "patch": {
    "title": "新标题",
    "repeat": "monthly",
    "endDate": "",
    "endMode": "open"
  }
}

长期规则只滚动维护未来两条待办；逾期未完成事项会继续保留。

POST/api/series/maintain

立即执行循环窗口维护。日常情况下由 EdgeOne 定时任务和页面启动兜底自动调用。

POST / DELETE/api/files

为事项保存 Logo 或小附件。单附件上限约 160KB，每条最多 5 个。

{
  "eventId": "evt-xxx",
  "icon": "https://example.com/logo.png",
  "file": {
    "name": "发票.pdf",
    "type": "application/pdf",
    "data": "data:application/pdf;base64,..."
  }
}

删除附件：

DELETE /api/files?eventId=evt-xxx&attachmentId=att-xxx

常见状态码

200 / 201成功
400字段或数据格式不正确
401未登录或 API_KEY 错误
404事项或循环规则不存在
503鉴权或存储暂时不可用
