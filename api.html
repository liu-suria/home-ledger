Beta v2.6.1 · 外部系统、快捷指令与自动化接入说明
返回事务中心

鉴权与通用约定

EdgeOne 环境变量中配置 API_KEY。外部请求任选一种方式携带：

X-API-Key: 你的 API_KEY

Authorization: Bearer 你的 API_KEY

网页已登录时也可通过 Session Cookie 调用。写接口统一使用 Content-Type: application/json。日期格式为 YYYY-MM-DD，币种使用大写代码，如 CNY、USD。

GET/api/types

查询当前可用类型。无需参数。

GET /api/types

返回：{ "types": [{ "id": "baby", "name": "宝宝事项" }] }

GET/api/events

查询事项，可组合筛选。

参数必填说明
days否从今天起查询未来 X 天，0–3650
type否类型 ID
status否pending 或 done
keyword否搜索标题、备注、支付方式和币种
start否开始日期
end否结束日期
calendar否solar 或 lunar
GET /api/events?days=30&type=baby&status=pending&keyword=疫苗

POST/api/events

新增一条单次事项。

字段必填说明
title是标题，最多 100 字
type是类型 ID
date是日期
calendar否默认 solar
lunarMonth / lunarDay阴历时农历月、日
amount否金额，最多两位小数
currency否默认 CNY
payment否支付方式
note否备注
icon否Logo 图片地址
{
  "title": "宝宝疫苗",
  "type": "baby",
  "date": "2026-08-15",
  "calendar": "solar",
  "amount": 0,
  "currency": "CNY",
  "note": "社区医院"
}

PATCH/api/events?id=事项ID

修改事项或切换完成状态。Body 中也可传 id。

{ "title": "修改后的标题", "date": "2026-08-20" }

{ "action": "done" }

{ "action": "restore" }

DELETE/api/events?id=事项ID

删除事项并移入回收站。

GET/api/today

查询今天未归档事项。无需参数。

GET/api/stats

返回今天、未来 7 天、未来 30 天、逾期、完成数、总数、订阅数与一年内人民币金额。

GET / POST/api/templates

GET 查询模板；POST 应用模板。

{ "id": "baby-basic", "startDate": "2026-08-02" }

GET/api/calendar?days=365

导出指定天数范围内的 ICS 日历文件。

GET / PUT/api/ledger

GET 读取完整账本；PUT 覆盖保存完整账本。主要用于备份、迁移和管理页面，不建议普通自动化直接使用。

{
  "version": 8,
  "settings": { "siteName": "Family Hub", "types": [], "typeOrder": [] },
  "series": [],
  "events": [],
  "trash": [],
  "logs": [],
  "templates": []
}

GET / POST/api/series

GET 查询循环规则；POST 操作循环。

字段说明
id循环规则 ID，必填
actiontopup、toggle、update、delete
scopesingle、future、all
from从哪一天开始影响
until补齐实例的截止日期
patch更新规则时的新字段
{
  "id": "series-xxx",
  "action": "update",
  "scope": "future",
  "from": "2026-08-02",
  "patch": { "title": "新标题", "repeat": "monthly", "endDate": "2027-08-02" }
}

GET / POST/api/backup

GET 返回最近 7 个历史备份清单；GET /api/backup?slot=0 读取指定备份；POST 恢复指定备份。

{ "slot": 0 }

POST / DELETE/api/files

为事项保存 Logo 或小附件。单附件上限约 160KB，每条最多 5 个。

{
  "eventId": "evt-xxx",
  "icon": "https://example.com/logo.png",
  "file": {
    "name": "发票.pdf",
    "type": "application/pdf",
    "data": "data:application/pdf;base64,..."
  }
}

删除附件：

DELETE /api/files?eventId=evt-xxx&attachmentId=att-xxx

常见状态码

200 / 201成功
400字段或数据格式不正确
401未登录或 API_KEY 错误
404事项、循环规则或备份不存在
503存储暂时不可用
